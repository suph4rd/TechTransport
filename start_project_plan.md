# Разработка MVP Tech Transport: этапы, задачи и подзадачи

Каждый этап заканчивается проверяемым результатом. Этапы выполняются последовательно; после каждого проект должен запускаться, а ранее готовые сценарии — работать.

## Текущий прогресс

Этап 1 выполнен 02.11.2026. Добавлены backend и frontend, Docker Compose с PostgreSQL и отдельными volumes, настройки окружения, SQLAlchemy и Alembic, единый формат ошибок, безопасное базовое журналирование и README с командами управления.

Проверено: запуск Compose, health/readiness напрямую и через frontend proxy, миграция `0001`, 3 backend-теста, TypeScript и production-сборка frontend, `npm audit` (0 уязвимостей), сохранность версии миграции и контрольного файла в volume фотографий после перезапуска. Визуальная проверка в браузере пока не проводилась. Тестовый клиент выдаёт предупреждение о будущем переходе Starlette с httpx на httpx2; тесты проходят.

Следующий этап: 2 — пользователи и авторизация.

## Допущения и отложенные работы

- «Любые фотографии» означает отсутствие требований к исходным пропорциям и сжатию; поддерживаемые форматы и технические пределы перечислены выше.
- Начальный справочник предоставляет ответственный за его содержание; демонстрационные данные не заменяют его наполнение.
- Для загрузки картографических тайлов нужен интернет.
- Реальные SMS, серверное развёртывание, S3, платежи и мониторинг production добавляются отдельными этапами после локального MVP.
